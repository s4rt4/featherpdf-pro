Feather PDF

Light on the system, full-featured on PDF.

An open-source, native PDF application for Linux, aiming at Adobe Acrobat-class capability without a web view. It wears Acrobat's bones (a tabbed workspace, a per-document command toolbar, a contextual Tools pane) with a quieter, modern GNOME skin.

One clean façade over mature engines

Feather doesn't reinvent a PDF engine. It orchestrates the best open-source libraries behind a single, coherent interface, and deliberately avoids in-process AGPL libraries to stay GPLv3.

Everything you do to a PDF, in one place

Click a card for the details.

A custom off-thread render pipeline with an LRU cache, so even a 4000-page document opens instantly.

  • Tabbed workspace, thumbnails, live find
  • Editable outline and document properties
  • Immersive reading mode with a floating page pill
  • Follow-along read-aloud via speech-dispatcher

Restructure documents losslessly: pages are rewritten, never re-rendered.

  • Rotate, delete, drag-to-reorder
  • Extract, insert, and crop page ranges
  • Merge and split documents
  • Edit the bookmark tree

Nine drag-to-place tools that write real PDF annotations any reader understands.

  • Highlight, underline, strikeout, sticky notes
  • Ink, shapes, lines, arrows, text boxes
  • Stamps: Approved, Draft, Confidential, For Review
  • Measure distance, perimeter, area; snapshot a region

Fill existing forms, or author new ones from scratch.

  • Text, checkbox, dropdown, radio, and button fields
  • Drag-to-place with a live preview
  • Prepare Form: auto-detect fields on plain layouts
  • Date/number/currency validation; XFDF import/export

True redaction that removes content, not a black box that merely covers it.

  • AES-256 encryption with permission controls
  • Find & Redact by pattern: emails, phones, IDs, custom regex
  • Sanitizer strips metadata, attachments, and scripts
  • See the pattern finder in action below

Signatures built to still verify in ten years.

  • Text or graphical appearance (PAdES / NSS)
  • PKCS#11 hardware tokens: smartcards, YubiKeys
  • RFC 3161 trusted timestamps
  • Long-term validation, step by step

From paper to searchable PDF in one pass.

  • Scan straight to PDF from any SANE device
  • Tesseract OCR with automatic language detection
  • Deskew, despeckle, and binarize pre-processing
  • OCR and image-to-PDF also available headless

In and out of PDF without leaving the app.

  • Office and image conversion via LibreOffice
  • Export to Word, ODT, RTF, and plain text
  • Pages to PNG/JPEG/TIFF; extract embedded images
  • PDF/A with preflight; RGB to CMYK; optimize and flatten

Everything works headless too.

  • A 21-command CLI, pipe-friendly
  • Batch wizard: chain operations, save them as actions
  • Watch folders, systemd-friendly daemon
  • Thumbnails, right-click actions, and a virtual printer
